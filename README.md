# SALVAGE IDOL Wiki

## このWikiについて

このWikiは、近未来SF企画 **『SALVAGE IDOL』** の世界設定・社会制度・技術・人物・物語上の前提を管理するための設定資料である。

本Wikiは単なるアイデア集ではなく、制作における **Single Source of Truth（設定の正本）** として使用する。

企画に関する設定について、会話ログ、メモ、過去の草案などと本Wikiの記述が矛盾する場合、原則として本Wikiに記載された最新の正式設定を優先する。

---

## 目的

本Wikiには、主に以下の3つの目的がある。

### 1. 制作者向け設定資料

世界観、社会制度、技術、人物などを体系的に整理し、制作中に必要な設定を参照できるようにする。

設定を個々のアイデアとしてではなく、相互に関連する世界設定として管理する。

### 2. 設定の正本

制作過程では、多数のアイデア、暫定設定、変更案が発生する。

それらと正式設定を区別し、「現在どの設定が有効なのか」を明確にする。

正式設定として採用された内容は、本Wikiへ反映することで確定する。

### 3. LLMからの参照

本Wikiは、人間だけでなくLLMから参照されることを前提として設計する。

ストーリー設計、シーン設計、本文生成、設定考証、矛盾検出などを行う際、必要なWikiページをコンテキストとして利用できる構造を目指す。

そのため、各ページは原則として**1ページ1概念**とし、ページ単体でも内容を解釈できるよう記述する。

---

# 設定ステータス

各設定ページには、設定の確定状態を示す `status` を付与する。

## CANON

正式に採用された現行設定。

制作時には原則としてCANONの内容を前提とする。

```yaml
status: CANON
```

## PROVISIONAL

暫定的に採用されている設定。

現時点では制作に使用できるが、今後の検討によって変更される可能性がある。

```yaml
status: PROVISIONAL
```

## IDEA

検討段階のアイデア。

候補として記録されているだけであり、作品世界の正式設定として扱ってはならない。

```yaml
status: IDEA
```

## DEPRECATED

以前は採用または検討されていたが、現在は廃止された設定。

現在の制作には使用しない。

設定変更の経緯を確認する必要がある場合のために保存する。

```yaml
status: DEPRECATED
```

# 情報の優先順位

設定が矛盾する場合、原則として以下の優先順位で判断する。

1. 本Wikiの `CANON`
2. 本Wikiの `PROVISIONAL`
3. その他の制作資料
4. 制作過程の会話ログ・検討記録
5. `IDEA`
6. `DEPRECATED`

`IDEA` および `DEPRECATED` の内容を、正式設定として本文生成や設定判断に使用してはならない。

同じステータスの設定同士が矛盾する場合は、更新日時だけで機械的に判断せず、矛盾事項として確認する。

# ページ構造

各設定ページは、原則としてMarkdown形式で作成する。

ページ冒頭にはYAML Front Matterを配置する。

基本形式は以下とする。

```yaml
---
title: IDOL
category: AI_SYSTEM
status: CANON
updated: 2026-08-23
related:
  - CHORUS
  - サルベージ
  - 網膜AR
---
```

## title

設定または概念の正式名称。

## category

設定が属するカテゴリ。

カテゴリはWiki全体の整理に使用する。

## status

設定の確定状態。

以下のいずれかを使用する。

* `CANON`
* `PROVISIONAL`
* `IDEA`
* `DEPRECATED`

## updated

設定内容を最後に更新した日。

形式は以下に統一する。

```text
YYYY-MM-DD
```

## related

直接関係する主要設定。

設定間の関係を把握するとともに、LLMが関連コンテキストを判断するための補助情報として使用する。

# 本文の基本構造

設定ページでは、必要に応じて以下のセクションを使用する。

```markdown
# 設定名

## 概要

設定の簡潔な定義。

## 詳細

設定の具体的内容。

## 社会における位置づけ

社会・文化・制度・生活などへの影響。

## 関連設定

関連するWikiページ。

## 制作上の注意

ストーリーや描写で守る必要がある制約、
誤解しやすい設定、
表現上重要となる事項。

## 未確定事項

今後検討する必要がある問題。
```

すべてのページで全セクションを使用する必要はない。

設定の性質に応じて追加・省略してよい。

# 記述原則

## 1ページ1概念

原則として、一つの主要概念を一つのMarkdownファイルとして管理する。

複数の独立した設定を一つの巨大なページへ集約しない。

一方で、情報量が少ない段階では過度な細分化を避ける。

## 明示的に記述する

他のページを読まなければ基本的な意味が理解できない記述は可能な限り避ける。

特に以下については省略せず記述する。

* その概念が何であるか
* 誰が利用するか
* 何のために存在するか
* どのような制約があるか
* 他の制度や技術とどう関係するか

## 設定と推測を区別する

正式に決まっていない内容を、説明を自然にするためだけに補完してはならない。

未確定の内容は `PROVISIONAL` または `IDEA` として明示する。

## 現実の考証と作品設定を区別する

科学技術、社会制度、歴史などについて現実世界の情報を参照した場合でも、

**現実に存在する事実**

と

**SALVAGE IDOL世界における設定**

を混同しない。

必要な場合は両者を明示的に分けて記述する。

# 設定変更

CANON設定を変更する場合、既存記述を単純に消去するのではなく、変更によって他の設定へ影響が発生しないか確認する。

特に以下との整合性を確認する。

* 関連するWikiページ
* 社会制度
* 技術設定
* 年表
* キャラクター設定
* 既存のストーリー
* 既に確定した出来事

重要な旧設定を残す必要がある場合は、`DEPRECATED` として保存する。

---

# 未確定設定

まだ独立ページを作るほど固まっていない問題や、複数設定にまたがる検討事項は `90_working/` で管理する。

正式採用された設定は、適切なカテゴリのページへ移動または反映する。

`90_working/` の記述は、CANONとして扱わない。

# LLMによる利用

LLMが本Wikiを参照する場合、以下の原則に従う。

1. `CANON` を正式設定として扱う。
2. `PROVISIONAL` は暫定設定であることを認識した上で使用する。
3. `IDEA` を正式設定として補完に使用しない。
4. `DEPRECATED` を現在の作品設定として使用しない。
5. Wikiに記載されていない情報を、既存設定であるかのように創作しない。
6. 設定間に矛盾を発見した場合、独自判断で解消せず指摘する。
7. 設定を追加・変更する場合、既存CANONとの整合性を確認する。
8. 個別ページだけで判断できない場合、`related` に指定された関連設定を参照する。

LLMによる提案・推測・生成内容は、それだけではWikiの正式設定にはならない。

制作者によって採用され、Wikiへ反映された時点で正式設定となる。

---

# 基本方針

このWikiの目的は、設定を増やすことではない。

**SALVAGE IDOLの世界を一貫したシステムとして維持し、制作上必要な情報へ確実にアクセスできる状態を作ること**を目的とする。

設定は物語を支えるために存在する。

したがって、設定の詳細化そのものを目的とせず、作品に必要な範囲で構築・更新する。
